# My Personal Portfolio Website

## About the Project
This is my personal portfolio website created as part of my HTML and CSS assignment. It showcases my profile, hobbies, academic achievements, certificates, and contact information.

## Technologies Used
- HTML5
- CSS3

## Features
- Personal introduction and profile photo
- About Me section
- Hobbies section
- Academic marksheets and certificates
- Sample HTML and CSS code
- Contact information
- Custom background image and styling
- CSS selectors, colors, fonts, spacing, borders, and box model properties

## Project Structure
- `index.html` — Main webpage
- `style.css` — Website styling
- `background.png` — Background image
- Image files — Profile photo, marksheets, and certificates

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.

## Learning Outcomes
Through this project, I practised HTML page structure, CSS styling, selectors, typography, backgrounds, borders, margins, padding, and the CSS box model.
